# 正式实验报告

实验标识：`experiment-96h`。9 组训练及最终成对评测全部完成；本报告使用已核验的实际产物。原始运行目录保留在本机，公开仓库仅保存统计和可核对的 SHA-256 指纹。

## 实验设置

- 基础模型：Qwen3.5-2B，BF16、未量化；RTX 3060 Ti 8GB，CUDA 11.8、PyTorch 2.7.1+cu118。
- 全部基础权重冻结，只训练 LoRA。混合配置覆盖 `q_proj/v_proj` 和 `in_proj_qkv/in_proj_z/in_proj_b/in_proj_a/out_proj`；全注意力对照只覆盖 `q_proj/v_proj`。
- 三个随机种子：42、43、44；LoRA dropout 0.05，alpha 为 rank 的两倍，batch size 1，梯度累积 16，学习率 1e-4，cosine 调度，warmup ratio 0.03，weight decay 0.01。
- 完整样本最长 512 token；答案与结束符参与监督，提示部分标签为 -100。超长样本整条过滤，未进行答案居中裁剪。
- 每组最多 3 epochs / 1356 个优化器步，每 50 步保存和验证；固定验证子集 128 条，连续三次未改善触发早停。
- 训练调度从 2026-10-15 07:41:51 UTC 至 2026-10-16 10:14:23 UTC，约 26.54 小时；最终评测在训练后完成。该时长包含调度与训练开销，不是纯 GPU kernel 时间。

## 数据与评测协议

源数据锁定为 `hfl/cmrc2018` 的提交 `137f2c45a24275fb68f6961c4d357f46288886aa`。训练、验证按源文档及归一化上下文分组，原始开发集作为留出测试；不复用界面里的虚构制度题。

| 分区 | 分组/增强后条数 | 512 token 过滤后 | 实际使用 |
| --- | ---: | ---: | --- |
| 训练 | 9540（含 422 条空上下文增强） | 7220 | 训练 |
| 验证 | 1024 | 723 | 固定 128 条用于早停和选择 |
| 留出测试 | 3219 | 2388 | 固定前 200 条用于成对评测 |

样本采用固定哈希顺序。每组的基础模型与适配器使用同一批题、相同提示与精度，贪心解码，`max_new_tokens=64`、`enable_thinking=false`。另取前 50 条测试题去掉上下文，构造受控拒答探针。

报告指标为归一化精确匹配 EM 和中文字符多重集 F1。它们与官方 CMRC 评分实现不同，不能作为官方榜单分数。基础模型重复评测结果一致，三种子标准差只描述不同 LoRA 训练随机性的波动，不是新测试样本的不确定区间。

| 配置 | EM 均值 ± 样本标准差 (%) | 字符 F1 均值 ± 样本标准差 (%) |
| --- | ---: | ---: |
| 基础模型 | 61.00 | 84.80 |

所有适配器的受控空上下文精确拒答率为 100%（50/50），基础模型为 98%（49/50）。适配器在有答案样本上的错误拒答率为 0%，基础模型为 0.5%（1/200）。这些数值不等于真实复杂场景下的无答案检测表现。

## 部署选择和结果解释

服务按九次运行的最低验证损失选择 `r16-hybrid-s43`（0.1407268），加载其最佳验证检查点导出的适配器；不读取测试分数进行选择。其单次测试分数为 EM 67.00%、字符 F1 89.71%。r16 的配置均值是 68.83% / 90.12%，与单个部署实例的分数应分开呈现。

本次固定样本上，r16 混合架构配置的平均 EM 比基础模型提高 7.83 个百分点，字符 F1 提高 5.32 个百分点。对三组配置的比较属于同一测试样本上的探索性分析；没有额外独立确认集，也未做统计显著性检验。

## 可核验性与限制

- `scripts.export_results` 检查 9 组完成状态、数据指纹、一致的测试 ID 与评测设置，并核对 18 份预测文件和 9 组适配器哈希；从预测文本重新计算公开指标。导出时移除全部原文、答案、预测、样本 ID、本机绝对路径与进程数据。
- 原始及派生训练数据、模型和适配器不随源代码提交。公开 SHA-256 用于关联本地证据，不等于第三方认证或数字签名。
- 200 道题的样本量有限；完整样本长度筛选排除了 831 条较长题，可能改变题目分布。
- 分组划分可降低本项目训练/测试交叉，但不能排除近重复文章和基础模型预训练污染。
- 任务是给定证据的短答案阅读理解；用户文档检索召回、长文理解、多轮对话、引用一致性是额外误差来源。此处指标不是文档助手的端到端业务分数。
- 运行顺序固定，系统负载和温度会影响时长。三个种子没有重复执行；不将运行速度或显存峰值差异归因于配置的单一因果作用。
